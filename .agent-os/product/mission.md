# Product Mission

> Last Updated: 2025-07-22
> Version: 1.0.0

## Pitch

Obsidian Telegram Sync is a desktop plugin that helps Obsidian users capture and organize information from Telegram directly into their knowledge vault by providing customizable rules and templates for automatic note creation and updates.

## Users

### Primary Customers

- **Knowledge Workers**: Professionals who use Obsidian for personal knowledge management and need quick capture from mobile
- **Content Creators**: Writers, researchers, and educators who collect information from various Telegram channels
- **Digital Note-takers**: Users who want seamless integration between their messaging and note-taking workflows

### User Personas

**Quick Capture User** (25-45 years old)
- **Role:** Knowledge worker, researcher, or content creator
- **Context:** Uses Telegram on mobile for consuming content and Obsidian on desktop for organizing knowledge
- **Pain Points:** Manual copy-pasting from Telegram, losing context when transferring information, inconsistent note formatting
- **Goals:** Capture ideas quickly from mobile, maintain organized notes, automate repetitive tasks

**Channel Curator** (30-50 years old)
- **Role:** Community manager, educator, or information curator
- **Context:** Manages or follows multiple Telegram channels with valuable content
- **Pain Points:** Information overload, difficulty organizing channel content, manual categorization work
- **Goals:** Automatically organize channel content, apply consistent formatting, filter relevant information

## The Problem

### Fragmented Information Capture

Mobile users consume valuable information on Telegram but struggle to transfer it to their Obsidian vaults efficiently. This results in lost insights and broken workflows between mobile consumption and desktop organization.

**Our Solution:** Automated synchronization that captures Telegram messages and files directly into Obsidian with customizable rules.

### Manual Processing Overhead

Users waste time manually copying, formatting, and organizing messages from Telegram into their notes. This repetitive work reduces productivity and disrupts creative flow.

**Our Solution:** Template-based processing that automatically formats and organizes content based on user-defined rules.

### Context Loss Between Platforms

Important context like sender information, timestamps, and channel metadata gets lost when manually transferring content between platforms.

**Our Solution:** Comprehensive metadata preservation and intelligent organization based on source channels and message types.

## Differentiators

### Rule-Based Processing

Unlike simple copy-paste solutions, we provide powerful rule engines that let users define exactly how different types of content should be processed. This results in consistently organized notes without manual intervention.

### Channel-Specific Templates

We allow users to configure different templates for different Telegram channels or chat types. This enables automatic categorization and formatting that matches each user's unique workflow.

### Flexible Storage Options

Unlike rigid sync solutions, we support both creating new notes and updating existing ones based on user preferences. This flexibility allows users to build their ideal knowledge management system.

## Key Features

### Core Features

- **Telegram Bot Integration:** Secure connection to personal Telegram bot for message reception
- **Text and File Sync:** Transfer text messages, images, documents, and voice transcripts
- **Voice Transcription:** Automatic transcription of voice messages (Premium feature)
- **Template System:** Customizable templates for formatting synchronized content

### Collaboration Features

- **Multi-Channel Support:** Add bot to multiple channels and groups for comprehensive capture
- **Selective Sync Rules:** Define which channels and message types to synchronize
- **Metadata Preservation:** Maintain sender info, timestamps, and channel context

### Organization Features

- **Smart Filing:** Automatically organize content into specified folders
- **Note Append/Create:** Choose between creating new notes or appending to existing ones
- **Markdown Formatting:** Automatic conversion to Obsidian-compatible markdown
- **Message Cleanup:** Option to delete processed messages from Telegram
